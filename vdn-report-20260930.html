更细粒度的记忆保留更统一的联合更新

新版 VDN 将记忆衰减从 head 级细化到通道级，并把逐帧写入改为 Chunk 级联合求解。本报告围绕这两项结构改进，说明更新逻辑、对应实现与评测表现。

核心结论
新版 FM50 在 VBench 中均分最高，在 VBench Long 中位列第二；两套评测均优于旧版 VDN/O1 FM50。

长视频并非全面领先：ARRHS FM50 的 Long 均分仍高出约 0.12 分。结果应按协议和维度分别解读。

01 /

改进方案与核心实现

两项改动分别回答两个问题：记忆的哪些通道应被保留，以及同一组待写入帧应怎样共同更新记忆。前者改变控制粒度，后者改变更新规则。

CHANGE A · RETENTION

通道级记忆衰减

旧方案用一个衰减系数控制整个 head。即便不同 key 通道承载的信息不同，它们也只能以同样的比例保留。新版给每个 head 的每个 key 通道分配独立系数，让记忆保留的控制更细。

旧方案

α ∈ ℝB×H
每个 head 一个系数
同一 head 内统一衰减

新方案

α ∈ ℝB×H×D
每个 key 通道一个系数
沿记忆矩阵的 key 方向缩放

记忆先验 · S 为 key × value 记忆矩阵S̃[b,h,d,:] = α[b,h,d] · S[b,h,d,:]
  • 参数形状：衰减投影输出从 H 扩展到 H×D，相关衰减参数同步扩展。
  • 计算路径：在帧内空间 token 上平均对数衰减，再取指数并重排为 [B,H,D]。
  • 作用范围：改变“保留多少历史”，不直接改变记忆矩阵的 key/value 维度。

设计意图是让不同通道学习不同的保留程度；具体语义分工仍由模型学习，不能仅凭参数形状断言某个通道专门负责主体或运动。

PYTHON · 通道级衰减
# One decay coefficient per head × key channel.
decay_dim = dim if variant == "vdn" else num_heads
self.a_proj = nn.Linear(dim, decay_dim, bias=False)
A = torch.empty(decay_dim, dtype=torch.float32).uniform_(0, 16)
self.A_log = nn.Parameter(torch.log(A))

# _prepare_frame_gates: spatial pooling in log space.
log_decay = (
    -self.A_log.float().exp()[None, None, :]
    * F.softplus(
        self.a_proj(x_frame).float()
        + self.dt_bias.float()[None, None, :]
    )
)
log_alpha = log_decay.mean(dim=1).clamp(min=-30.0, max=0.0)
alpha = log_alpha.exp().reshape(
    x_frame.shape[0], self.num_heads, self.head_dim
)

CHANGE B · COMMIT

Chunk 级联合记忆更新

旧方案把离开局部窗口的帧逐个写入，每次写入都会改变下一帧面对的记忆。新版先汇总这组帧的统计量，再联合求解一次，得到新的长期记忆。

旧方案

逐帧递推
S₀ → S₁ → … → SF
每一步使用上一步结果

新方案

一次联合提交
汇总 F 帧 → 求解 → S′
共享同一个更新前状态

联合更新方程 · A 为各帧通道衰减的乘积A = ∏f αf　 G = ∑f Gf　 W = ∑f Wf
(I + sym(G)) S′ = A ⊙ S + W
  • 汇总：对 gram、write 求和，对通道衰减求乘积。
  • 求解：关闭混合精度，在 FP32 下对对称化后的系统做 Cholesky 求解。
  • 提交：仅将本次离开局部重叠区的帧写入长期记忆。

这定义了新的更新目标，不是旧版逐帧递推的等价加速。一次提交包含 F 帧时，矩阵分解从 F 次降为 1 次；尚无独立的端到端加速测量。

PYTHON · Chunk 联合更新
# _apply_write_group: commit departing frames together.
if not statistics:
    return state

with torch.autocast(device_type=state.device.type, enabled=False):
    alpha = torch.stack(
        [s["alpha"].float() for s in statistics], dim=0
    ).prod(dim=0)
    gram = torch.stack(
        [s["gram"].float() for s in statistics], dim=0
    ).sum(dim=0)
    write = torch.stack(
        [s["write"].float() for s in statistics], dim=0
    ).sum(dim=0)
    eye = torch.eye(
        state.shape[-2], device=state.device, dtype=torch.float32
    )
    system = eye + 0.5 * (gram + gram.transpose(-1, -2))
    chol = torch.linalg.cholesky(system)
    result = torch.cholesky_solve(
        alpha[..., None] * state.float() + write, chol
    )
return result

对应源码：hybrid_attention.py · _apply_write_group（约 494 行）。节选省略诊断记录，并将长表达式拆行；system 为原表达式的临时变量。

与原有因果记忆路径的衔接

以下是沿用的读写边界，而非新增贡献：保留最近一帧 clean KV，保留原始 RoPE 时间位置；本 Chunk 先读取旧记忆，再提交离开局部重叠区的帧。

01 · READ读取同一份旧记忆

本 Chunk 的 token 共享更新前状态。

02 · RETAIN保留局部 clean KV

最近一帧继续留在局部重叠区。

03 · COLLECT汇总离开窗口的帧

仅收集本次应提交的帧统计量。

04 · COMMIT联合求解并更新

避免同一帧在局部与长期记忆中重复写入。

实现验证：核心实现已在 CPU 上与正式源码对照，输出及输入梯度在测试容差内一致，并通过独立稠密矩阵方程检查。此检查验证代码实现，不替代结构消融实验。

评测口径与可追溯性

输入与评分范围
四模型原始比较的 30 条 prompt 按已有分数筛选后固定，其余模型在同一清单上补测。主体与运动共用 10 条，背景用另 10 条，美学与成像共用最后 10 条；不是每条视频都评分五遍。本报告不代表完整官方榜单。

聚合规则
只报告五个维度，不含时间闪烁。各维转为百分制，五维均分按未舍入分数等权计算，展示值保留两位小数；文中差值也由未舍入值计算。

视频与 Long 协议
VBench 使用 81 帧视频，VBench Long 使用 501 帧视频。Long 每维对应 10 条原始视频，按本次评分协议产生 160 个两秒片段。

模型与审核
ARL2 ARRHS 与 Sep07 ARL2 FlashMorph 是不同变体；Causal Forcing 使用 chunkwise teacher。两套评测、两类结果来源共四份最终审计均 verified_complete，并绑定同一份 prompt 清单。
