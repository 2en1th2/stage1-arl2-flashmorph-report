ARL² → Frame-GDN：改变写入单位

将同一帧的空间 token 一起处理，再按帧推进。先用衰减后的旧记忆预测当前帧的 V，再把预测残差写回记忆。

M̄ = αMold
Mnew = M̄ + KᵀB(V − KM̄)

这是示意式；Frame-GDN 显式实现还含空间归一化，不能将其视为逐行代码。

Frame-GDN → VDN：隐式加权拟合

同时保留衰减后的历史记忆并拟合当前帧，将帧内空间 token 的相互影响纳入一次联合求解。

minM ½‖M − αMold‖²F
　 + ½∑u βu‖kuM − vu‖²2

K、V 按空间 token 排列；B = diag(β)。M 为每个注意力头的历史记忆。

(I + KᵀBK)Mnew = αMold + KᵀBV

实际使用 FP32 Cholesky 求解，不显式计算矩阵逆。质量和速度的收益仍需通过实验判断。

α · 历史保留

每头、每帧一个系数。由空间 token 的 log-decay 取均值后指数化得到。

β · 写入权重

每个空间 token 的权重为 2 × sigmoid(·)。当前 VDN 分支不再乘 D/S。

Output gate · 读出贡献

控制历史记忆读出对最终结果的贡献，与 α、β 的作用不同。

02 / CONTEXT

最近 1 帧保留精确信息，远期历史写入记忆

以生成第 4–6 帧为例：局部 softmax 读取第 3 帧的 clean K/V 与当前块；压缩记忆仅包含第 1–2 帧。

第 1–2 帧远期压缩记忆
第 3 帧clean K/V · overlap
第 4–6 帧当前块 · 局部 softmax

第 4–6 帧的最终 clean pass 提交后，第 3–5 帧进入远期记忆，第 6 帧保留为下一块的 overlap。这样，同一历史帧不会同时出现在精确 K/V 和远期记忆中。

去噪过程中只读，最终 clean pass 才提交状态。当前 3 帧块内可相互注意，因此不是严格逐帧因果；实现中的“帧”指注意力块处理的 latent frame。

1. 每帧历史保留系数与逐 token 写入权重

α 由空间维度上的 log-decay 均值生成，并限制 log 值范围；β 保留每个 token、每个头的自适应写入权重。

def _prepare_frame_gates(self, x_frame):
    """Return one decay per frame/head and one write weight per token/head.

    Historical ARL2 predicts a tokenwise log decay.  A frame is one
    recurrent event here, so the permutation-invariant geometric mean is
    used: alpha = exp(mean(log_decay)).  Beta remains data-dependent per
    spatial token.  The historical ARL2 range 2*sigmoid(.) is retained.
    """
    log_decay = -self.A_log.float().exp()[None, None, :] * F.softplus(
        self.a_proj(x_frame).float() + self.dt_bias.float()[None, None, :]
    )
    log_alpha = log_decay.mean(dim=1).clamp(min=-30.0, max=0.0)
    alpha = log_alpha.exp()
    beta = self.b_proj(x_frame).float().sigmoid() * 2.0
    return alpha, beta

2. Frame-GDN：显式残差修正

显式实现先将 K 除以 √S，再计算 prediction、residual 和 delta。因此上面的未归一化公式仅用于说明更新机制。

hybrid_attention.py · L360–L376
def _explicit_frame_update(self, state, k_frame, v_frame, alpha, beta):
    """SANA-style explicit frame delta rule in ARL2 state orientation.

    ARL2 keys are already L2-normalized.  Dividing by sqrt(S), rather than
    sqrt(D*S), therefore matches SANA's frame normalization without an
    extra head-dimension shrinkage.
    """
    spatial_tokens = k_frame.shape[1]
    k_hat = k_frame.float() * (float(spatial_tokens) ** -0.5)
    v_fp32 = v_frame.float()
    prior = alpha[..., None, None] * state.float()
    prediction = torch.einsum("bshd,bhdv->bshv", k_hat, prior)
    residual = v_fp32 - prediction
    delta = torch.einsum(
        "bshd,bshv->bhdv", k_hat, beta[..., None] * residual
    )
    return prior + delta, None

3. VDN：FP32 Cholesky 隐式求解

gram 对应 KᵀBK，write 对应 KᵀBV。对 Gram 矩阵做对称化后分解，并通过 cholesky_solve 求解；这里没有 D/S 写入缩放，也没有显式求逆。

hybrid_attention.py · L405–L419
def _vdn_frame_update(self, state, k_frame, v_frame, alpha, beta):
    """VDN-inspired proximal solve, in ARL2's [key, value] orientation.

    min_M .5||M-alpha*M_old||² + .5 sum_u beta_u||k_u M-v_u||².
    Unlike legacy implicit, beta is NOT rescaled by D/U. We retain
    Frame-GDN's scalar/head decay (not VDN's channelwise decay).
    """
    with torch.autocast(device_type=k_frame.device.type, enabled=False):
        k, v = k_frame.float(), v_frame.float()
        gram = torch.einsum("buhd,buhe->bhde", k, beta.float()[..., None] * k)
        write = torch.einsum("buhd,buhv->bhdv", k, beta.float()[..., None] * v)
        eye = torch.eye(k.shape[-1], device=k.device, dtype=torch.float32)
        chol = torch.linalg.cholesky(eye + 0.5 * (gram + gram.transpose(-1, -2)))
        result = torch.cholesky_solve(alpha.float()[..., None, None] * state.float() + write, chol)
    return result, chol.diagonal(dim1=-2, dim2=-1)

4. 帧级统计并行计算，再按帧顺序更新

上下文路径批量计算各帧的 Gram / write / Cholesky 统计，再用 _apply_frame_statistics 顺序推进记忆。代码中的 legacy implicit 分支仍乘 D/S；当前 vdn 分支保留 rho = beta，二者需区分。

def _frame_write_statistics(self, x, k, v, frame_seqlen):
    """Batch frame-local work; sequential recurrence remains out-of-place.

    Pending halo stores sufficient statistics, not hidden activations.
    Cholesky is batched over frames, batch and heads, only on clean writes
    in inference. No inverse is materialized.
    """
    B, L, H, D = k.shape
    if L % frame_seqlen:
        raise ValueError("Frame write requires complete frames")
    frames = L // frame_seqlen
    alpha, beta = self._prepare_frame_gates(x.reshape(B * frames, frame_seqlen, self.dim))
    alpha = alpha.reshape(B, frames, H)
    beta = beta.reshape(B, frames, frame_seqlen, H)
    k = k.float().reshape(B, frames, frame_seqlen, H, D)
    v = v.float().reshape(B, frames, frame_seqlen, H, D)
    rho = beta
    if self.frame_gdn_variant == "explicit":
        k = k * (frame_seqlen ** -0.5)
    elif self.frame_gdn_variant == "implicit":
        rho = beta * (D / frame_seqlen)
    with torch.autocast(device_type=k.device.type, enabled=False):
        gram = torch.einsum("bfuhd,bfuhe->bfhde", k, rho[..., None] * k)
        write = torch.einsum("bfuhd,bfuhv->bfhdv", k, rho[..., None] * v)
        chol = None
        if self.frame_gdn_variant != "explicit":
            eye = torch.eye(D, device=k.device, dtype=torch.float32)
            chol = torch.linalg.cholesky(eye + 0.5 * (gram + gram.transpose(-1, -2)))
    return [dict(alpha=alpha[:, f], beta=beta[:, f] if self._diagnostics_enabled else None,
                 write=write[:, f], gram=gram[:, f] if chol is None else None,
                 chol=chol[:, f] if chol is not None else None) for f in range(frames)]

def _apply_frame_statistics(self, state, stats):
    chol = stats["chol"]
    with torch.autocast(device_type=state.device.type, enabled=False):
        prior = stats["alpha"][..., None, None] * state.float()
        if chol is None:
            result = prior + stats["write"] - stats["gram"] @ prior
        else:
            result = torch.cholesky_solve(prior + stats["write"], chol)
    if self._diagnostics_enabled and stats["beta"] is not None:
        self._record_frame_diagnostics(alpha=stats["alpha"], beta=stats["beta"], state_before=state, state_after=result,
            solve_diag=chol.diagonal(dim1=-2, dim2=-1) if chol is not None else None)
    return result
